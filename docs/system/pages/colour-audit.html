The GEOM zones 3 palettes

Not in the CSS audit above, because these live in an .svg. The same four landings carry three different sets of values that have never been reconciled: ReCal's muted in-app zones, the saturated marketing hues in the GEOM map, and the lightness-lifted dark-mode set derived from them. Hue angle is close across all three; saturation and lightness are not.
