The budget

Some changes the type requires to stay itself at a new setting. They carry no meaning and cost nothing. Others are made in order to say something, and those are the ones we ration. There are six.

The sixth signal: geom

Same size, weight, color, and case — the letters are simply built differently. Four landings, at 0 · 25 · 50 · 100. Each sits in the middle of a pad the font holds flat, so the landing is a plateau rather than a point — which is what makes it a decision you can return to instead of a number you happened to drag to.

The pads are the font’s, not ours: A11y holds to 10, UI runs 16–34, Base 40–60, Geo from 80 up. Inside a pad the drawing barely moves, so precision buys nothing. Between pads it moves fastest, which is why a value like 37 is the worst of both — it belongs to no landing and reads as drift.

The poster scale

The seven roles stop at 45px — the largest size chrome has any business being. Above it is a different instrument: the monster sample. And up there the naming rule inverts. At text sizes you name the job, because size alone doesn’t tell a reader what a thing is. At display sizes the job is magnitude — 96px isn’t a different kind of thing from 136px, it is the same thing, larger. So here a ladder is honest, where in the text scale it would have been a dodge.

Mea

Ratio √2 — the paper ratio, the one the A-series is built on, so every second step doubles exactly: 48 → 96 → 192. Tailwind’s 5xl–9xl walks 1.25, 1.20, 1.33, 1.33 — four intervals pretending to be a scale.

Leading tightens as the steps climb — a compensation. Tracking does not, and that is the rule: hand-tracking display type is what you do when a font has no optical size axis. Ours has one, so the fit tightens by itself.

Ink

Grey is a signal, so there are three of it, not a gradient. Each is expressed as opacity on the text color, so they compose over any ground and stay honest in both themes.

--ink-full The text is the text. 1.00
--ink-quiet Subordinate: captions, annotations, spec data. 0.62
--ink-faint Structural only: rules, disabled, watermarks. 0.38

An arbitrary alpha is not an ink. All three rows above are one size, because quiet comes from ink at the size the context calls for — never from a smaller role and a lighter grey.

--signal Hue is not an ink, and not one of the six signals. #eeff41 · #5c6b00

The acid yellow on dark, and its olive on light, are doing one job: pointing at the thing under discussion — the value being explained, the word the sentence is about. It never marks hierarchy and it never means “important.” The moment a color means important, it can no longer mean anything else, and every future use of it has to fight the one before.

Why opsz is free

Both lines are set at the title size in the same font. Only the optical size differs. This is what the type does to stay itself across sizes — a compensation, not a statement. Which is precisely why it must ride inside the token and never count against the budget.

Handgloves at eight
26px · opsz 8 — drawn for small sizes: open spacing, sturdier strokes. Set large, it reads clumsy.
Handgloves at forty-five
26px · opsz 45 — drawn for display: tighter fit, finer joins. Set small, it falls apart.

The one exception: opsz pinned while the size changes is a deliberate mismatch. That is no longer a compensation. It is a signal, and it is spent.
