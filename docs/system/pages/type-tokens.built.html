The budget

Some changes the type requires to stay itself at a new setting. They carry no meaning and cost nothing. Others are made in order to say something, and those are the ones we ration. There are six.

Compensations — free

  • trackingcaps only, one value. Size is opsz’s job.
  • leadinganswers to size and measure.

One signal per distinction. Compensations ride along free.

Never ink + size + case together. Three ways of saying “minor” is not emphasis — it is a lack of confidence.

The exception that proves the first rule: opsz pinned while size changes is a deliberate mismatch. That is no longer a compensation. It is a signal, and it is spent.

The sixth signal: geom

Same size, weight, colour, and case — the letters are simply built differently. Four landings, at 0 · 25 · 50 · 100. Each sits in the middle of a pad the font holds flat, so the landing is a plateau rather than a point — which is what makes it a decision you can return to instead of a number you happened to drag to.

The pads are the font’s, not ours: A11y holds to 10, UI runs 16–34, Base 40–60, Geo from 80 up. Inside a pad the drawing barely moves, so precision buys nothing. Between pads it moves fastest, which is why a value like 37 is the worst of both — it belongs to no landing and reads as drift.

The poster scale

The seven roles stop at 45px — the largest size chrome has any business being. Above it is a different instrument: the monster sample. And up there the naming rule inverts. At text sizes you name the job, because size alone doesn’t tell a reader what a thing is. At display sizes the job is magnitude — 96px isn’t a different kind of thing from 136px, it is the same thing, larger. So here a ladder is honest, where in the text scale it would have been a dodge.

Mea

Ratio √2 — the paper ratio, the one the A-series is built on, so every second step doubles exactly: 48 → 96 → 192. Tailwind’s 5xl–9xl walks 1.25, 1.20, 1.33, 1.33 — four intervals pretending to be a scale. Two of our five steps (68, 96) were already in the codebase.

Leading tightens as the steps climb — a compensation. Tracking does not, and that is the rule: hand-tracking display type is what you do when a font has no optical size axis. Ours has one, and opsz is already tightening the fit at every step. Doing it again by hand double-counts the axis we built the product on.

Ink

Grey is a signal, and we were spending it like punctuation. Four levels resolved to 1.00 · 0.64 · 0.40 · 0.24 on our ground — a finer gradation than a page can mean. Three, expressed as opacity on the text colour so they compose over any ground and stay honest in both themes.

--ink-full The text is the text. 1.00
--ink-quiet Subordinate: captions, annotations, spec data. 0.62
--ink-faint Structural only: rules, disabled, watermarks. 0.38

Three values, and only three: 1.00, 0.62, 0.38. An arbitrary alpha is not an ink. All three rows above are one size, because quiet comes from ink at the size the context calls for — never from a smaller role and a lighter grey.

--signal Hue is not an ink, and not one of the five signals. #4a7fd4

The acid yellow throughout is doing one job: pointing at the thing under discussion — the value being explained, the word the sentence is about. It never marks hierarchy and it never means “important.” The moment a colour means important, it can no longer mean anything else, and every future use of it has to fight the one before.

The correction

The label role as it stood said “minor” four times. A label is not less important than the thing it labels; it is a different kind of thing — so it should differ in kind, not in importance.

Why opsz is free

Both lines are set at exactly 34px in the same font. Only the optical size differs. This is what the type does to stay itself across sizes — a compensation, not a statement. Which is precisely why it must ride inside the token and never count against the budget.
