Five ways to draw one dial

The same three controls in every variant — one with a unit, one with a tag, one with neither — so the labelling question stays visible while you compare the shapes.

01 has landed. The primitive is a single text field now, so every dial prints a real minus instead of a hyphen; the stepper is drawn rather than the browser's, which means it looks the same in every engine instead of the two different controls font-proofer and ReCal were showing; and both halves of the control clamp, where before you could type 1200 into a 400–700 axis and read it back while the type rendered at 700. The other four are still proposals.

Why not all three slots, always

labelAlways. What the dial is.
tagOnly when a second real name exists. wght, opsz, wdth are in the font binary and in font-variation-settings. Invent one for size and none of them can be trusted as the axis name any more.
unitOnly when the value has one. If you can't say what it is a unit of, there isn't one — leading 1.6 is a ratio, and a × would misstate the number's type.
all threeReal, and we handle it badly. wdth is a percentage: width · wdth · 102.5%. So the primitive must support three slots without requiring them.
try

Every field is typeable and clamps to its range — type 1200 into weight and watch it come back. Arrows are ours, not the browser's, so they look the same everywhere and can hide until you approach. Vertical uses writing-mode: vertical-lr on the range, which needs no wrapper and no rotate transform.
